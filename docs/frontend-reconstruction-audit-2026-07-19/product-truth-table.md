# TopicAI 前端页面产品真值表

## 分类定义

| 分类 | 含义 |
|---|---|
| 保留 | 页面职责和领域模型正确，只需补齐能力与视觉 |
| 项目内合并 | 能力有价值，但不再作为独立工具页 |
| 重构 | 保留一级入口或用户目标，重新定义页面和数据契约 |
| 兼容跳转 | 退出主导航，短期保留旧 URL 并跳转到新上下文 |
| 退出 MVP | 不进入小红书知识/经验型图文首版 |

## 一级入口

| 当前入口 | 当前实现 | 决策 | 新职责 | 可复用内容 | 主要缺口 |
|---|---|---|---|---|---|
| `/login` | 登录 + 旧产品营销 | 重构 | 身份验证、两类用户进入前的可信产品承诺 | auth API、authStore、表单校验 | 新价值表达、未实现入口处理、错误恢复 |
| `/` 今日 | 假数据大屏 + 工具快捷入口 | 重构 | 唯一主要 NextBestAction、本周目标、少量次要动作 | 壳层、认证信息、部分空状态组件 | CreatorState、Action 服务、真实指标 |
| `/content` | 内容项目列表 | 保留 | 周计划、项目组合、断点恢复、筛选和实验状态 | v2 项目列表 API、状态枚举、移动端布局 | 计划字段、阻塞、证据覆盖、项目分组 |
| `/content/:id` | 阶段表单 + 校准结果 | 保留并重排 | 项目时间线、Brief、证据、版本、发布、数据、复盘、观察 | v2 校准工作区、发布/快照/盲评/Observation 服务 | 统一时间线、证据引用、版本比较、HumanGate |
| `/topics` 机会 | 实时热点 AI 选题 | 重构 | 有来源的机会候选、匹配理由、准备度、系列潜力和实验作用 | 搜索/筛选交互、部分推荐卡组件 | Opportunity v2、证据来源、创建项目动作 |
| `/assets` 素材 | 完整多媒体 DAM | 收缩重构 | 项目内素材抽屉 + 轻量跨项目素材列表 | 上传、搜索、文件存储、标签、使用记录 | Material v2 语义、项目引用、事实/案例/观点分类 |
| `/profile` 我的 | 三步赛道画像问卷 | 拆分重构 | CreatorState、内容策略、账号、隐私和设置 | profile API 的部分字段、表单组件 | 新手/成长型分流、历史导入、事实确认、版本化策略 |

## 旧工具路由

| 当前路由 | 当前能力 | 决策 | 新归属 | 兼容策略 |
|---|---|---|---|---|
| `/writing` | 独立写作建议 | 项目内合并 | 内容项目的 Brief、采访和创作工作台 | 有项目上下文时跳转对应项目；无上下文跳到内容列表 |
| `/ideas` | `/writing` 别名 | 兼容跳转 | 机会详情或内容 Brief | 仅保留旧链接解析，不保留独立页面 |
| `/titles` | 独立标题优化与评分 | 项目内合并 | ContentVersion 的标题候选与局部建议 | 跳到项目创作工作台，不展示伪精确评分 |
| `/viral` | 爆款拆解、爆款指数 | 项目内合并/部分退出 | 外部样本证据和结构参考 | 移除爆款指数；有来源样本可进入项目证据 |
| `/publish` | 最佳发布时间建议 | 项目内合并 | 发布检查、计划时间和手动发布记录 | 跳到项目发布阶段；不承诺最佳时机 |
| `/analytics` | 泛化数据大屏 | 退出主导航 | 项目真实数据、内部验证指标 | 用户侧跳到内容/今日；内部指标另建受限入口 |
| `/review` | 发布前预测 + 旧效果复盘 | 兼容跳转后退出 | 项目盲评、Review 和 Observation | 旧记录只读迁移；新记录必须进入内容项目 |
| `/tracks` | 赛道健康和竞争诊断 | 合并/退出 | 新手候选方向实验、我的内容策略 | 不提供永久赛道结论和竞争度伪评分 |
| `/accounts` | 多平台账号管理 | 退出 MVP | 我的 > 小红书账号引用 | 首版仅保留一个主要小红书账号的手动引用 |

## 旧首页组件

| 组件 | 决策 | 原因 |
|---|---|---|
| 欢迎/设置横幅 | 重构 | 需要根据新手或成长型状态给出真实下一步 |
| 四项指标卡 | 删除 | 当前数据无稳定来源，且首页不应成为泛化大屏 |
| AI 调用额度 | 移到设置或异常提示 | 额度不是用户的主要工作目标 |
| 三个工具快捷按钮 | 删除 | 继续要求用户选择工具，与 AI-native 目标冲突 |
| 最近动态 | 改为项目事件流 | 可复用时间线表达，但必须来自真实 ActionEvent/ProjectEvent |
| AI 建议卡 | 替换为 NextBestAction | 必须包含理由、证据、预期状态变化、门控和降级 |
| 右侧通用快捷面板 | 删除 | 缺少上下文且重复 CTA |

## 组件与基础设施复用

| 模块 | 复用等级 | 处理方式 |
|---|---|---|
| `services/api/client.ts` | 高 | 保留 JWT 刷新和 v1/v2 客户端工厂 |
| `store/authStore.ts` | 高 | 保留认证状态，补错误恢复和账号迁移提示 |
| `components/layout/Sidebar.tsx` | 中 | 保留五导航和图标，重做桌面密度、用户入口和状态提示 |
| `components/layout/AppLayout.tsx` | 中 | 保留响应式壳层，删除通用右栏假设，支持页面级工作区布局 |
| MUI theme/tokens | 中 | 保留基础色与尺寸，重新冻结字体层级、间距和状态色 |
| v2 Content API/contracts | 高 | 作为新版内容闭环的事实来源 |
| `features/content/StageForms.tsx` | 中高 | 保留命令逻辑，拆成项目时间线和阶段工作区组件 |
| `ReviewSummary` / `ObservationList` | 高 | 保留语义和服务契约，补证据解释与生命周期反馈 |
| 素材上传/存储 API | 中高 | 保留基础能力，前端信息架构改为项目优先 |
| 旧推荐/标题/爆款/发布 API | 低 | 只作为兼容或局部能力来源，不再决定一级页面 |
| 旧测试 | 中 | 保留底层服务契约测试；页面测试随路由迁移重写 |

## 开工前必须冻结的产品决策

1. 新手和成长型用户是系统自动识别还是用户主动选择。
2. `机会` 是否统一包含用户问题、历史缺口、外部事实、系列机会和实验机会。
3. 旧路由兼容周期，以及是否需要迁移旧记录。
4. 首轮前端是否允许用契约模拟尚未实现的 `NextBestAction`，还是先完成后端。
5. “我的”中 CreatorState、内容策略、账号和隐私的页面层级。
6. 首轮视觉方向选择：任务驱动型、项目工作台型或编辑器中心型。

## 建议实施顺序

1. 登录承诺与新手/成长型分流。
2. 今日 NextBestAction。
3. 内容列表和项目工作台重排。
4. 机会 v2。
5. 项目内素材抽屉和轻量素材页。
6. 我的/CreatorState/设置。
7. 旧路由兼容跳转与旧页面下线。
