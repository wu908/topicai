> 日期：2026-10-11

---

## 0. 一句话

在**不推翻**现有 ContentProject / `/api/v2` / 测试红线的前提下，把「10 入口表单海」收成  
**垂直内容 Agent**：人只输入和决策，AI 四层技能干活，双记忆越用越准。

---

## 1. 目标态（三层）

```
人     输入 + 决策
产品   今日待决 · 内容（对话+产物）· 复盘 · 路径 · 素材 · 我的
Agent  编排 + 发现/成稿/门禁/归因 + 双记忆 + 进化回路
```

**主闭环七步**：想发 → 对话成稿（内嵌人话化）→ 发前门 → 登记发布 → 对账 → 准/偏 → 写回路径（人确认）。

---

## 2. 分阶段骨架（一步一步）

| 阶段 | 目标 | 主要动作 | 人感变化 | 退出标准 |
|---|---|---|---|---|
| **P0 收敛** | 砍假象、并入口、锁黄金路径 | 删假状态/假输入；导航 10→6 预案；G4 同源补齐；一条 E2E 黄金路径 | 少迷路 | 旧功能不丢、测试绿 |
| **P1 链路** | 七步主链可走 | 内容页=待决+对话/产物；表单改内联决策卡；发前检查一键修；发布登记简化 | 少填表 | 一条内容从想到发不再跳页填表 |
| **P2 人味** | 发得出去 | 内嵌去 AI 味+事实保真；bet 留底；对账≤2 数+准/偏摘要 | 稿像人、账清楚 | 发前门+对账跑通 |
| **P3 路径** | 持续发展 | 路径画像；判断记忆；公式笔记（提案制）；对标锚 | 系统像懂我 | 收/不收经验闭环 |
| **P4 进化** | 越判越准 | 学习信号入库；规则回放对比；提示词/公式版本 | 「变准了」可感知 | 连续 N 条后建议可核验 |
| **P5 扩展** | 后置能力 | 多平台发布；形态（卡片/视频脚本）；harness 对接 | 自动化加深 | 按需开 |

**每阶段结束都要你点头**；单阶段可独立回滚。

## 4. Agent 能力落阶段（已确认 §8）

| 能力 | 阶段 |
|---|---|
| 现有 AI 收进四层技能（发现/成稿/门禁/归因） | P1 |
| 内嵌去 AI 味、发前一键修、bet | P2 |
| 双记忆（路径画像+判断记忆，提案制） | P3 |
| 进化回路（规则/公式/提示词，回放校验） | P4 |
| Harness 后接 | P5 |

---

## 5. 红线（全程）

1. 人只输入和决策；AI 不绕过四决策  
2. 不编造、可溯、可撤销  
3. 记忆/公式写入默认提案，人确认生效  
4. 不吹「预测会爆」；多平台自动发布后置  
5. `/api/v2` only、additive migration、TDD≥80%、无死路  

---

## 6. 内容页改造与 Agent 的接口（P1 概念）

| UI | 调用的 Agent 行为 |
|---|---|
| 今日待决列表 | 编排器：待决策/待对账/路径提醒 |
| 对话流 | 技能：深挖/起草/检查/对账 |
| 右栏产物 | 技能输出 + 可编辑 |
| 决策卡 | HumanGate（发布/经验/隐私/删除） |
| （无 UI） | 人话化、溯源、检查静默跑 |
