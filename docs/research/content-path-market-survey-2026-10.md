# 内容页产品假设重定 · 市场与项目调研（2026-10）

> 触发：主任务从「把一次真实经历变成内容并知道有没有用」修正为
> **「找到自己想发的 → 发出去 → 选一条合适路径 → 持续发展」**。
> 用户要求：路径/需求讨论必须结合市场、成熟项目、社区，**先调查 → 再分析 → 再确定**。
> 参考项目：https://github.com/XBuilderLAB/cheat-on-content
> 通道：gh / Exa（agent-reach）/ WebFetch；WebSearch 本机不可用。

---

## 1. 调研问题

1. 市场上「找到想发的 / 选路径 / 持续成长」分别被什么产品解决？

3. TopicAI 现有 ContentProject 模型与上述需求错位在哪？

## 2. 参考项目深挖：cheat-on-content

| 项 | 事实 |
|---|---|
| 热度 | ~7.2k stars，MIT，Python/Agent Skills 形态（非 SaaS UI） |
| 一句话 | 把每条内容变成**可校准实验**：打分 → 盲预测 → 发布 → T+3 复盘 → 进化 rubric |
| 核心主张 | 别人帮你「产出更多」，它帮你「**判得更准**」；AI 判、稿子还是你的 |
| 三原则 | ① 盲预测 immutable ② 升级 rubric = 全量重打 + 跨模型审 ③ rubric 是工作台不是博物馆 |
| 入口 | `/cheat-init` → 导入对标 → seed 选题 → score/predict → shoot/publish → retro → bump |
| 选题观 | **对话式一次一个**（用户给经历/想法，AI 深挖角度写 draft），不是 AI 甩 15 个候选 |
| 对标 | `/cheat-learn-from`：5–10 条对标样本当冷启动 anchor |
| 推荐 | 候选池按 rubric 排序，「1 稳 + 1 实验」，排除已发/已拒 |
| 节奏 | buffer（拍了没发）警戒 + cadence 协议 |
| 形态覆盖 | 方法论通用，**内置 rubric 仅观点视频**；长文/短文 starter 路线图中（issue #76） |
| 平台适配 | adapters：B站/抖音/视频号/LinkedIn/小红书 explore + 热点源 |

### 社区真实声音（Issues）

| 来源 | 观点 |
|---|---|
| #71 标题（争议） | 「纯自 high」「别浪费时间，老老实实学习复盘」 |
| #71 主楼 | AI 打分≠算流量；忽略成片/封面/发布时间/随机性；**既当裁判又当运动员**（用旧样本改规则又验规则） |
| #71 评论 | 「训练集里扔验证集 → 过拟合」「预测流量 overhype；**当复盘工具还有点用**」 |
| 作者/维护者辩护 | 「算流量是手段不是目的，核心是复盘 + 复利」 |
| #76 / #77 | 要多形态（公众号/小红书）；文字形态配固定频率后 buffer 永远警报 |

**对 TopicAI 的启示（诚实版）**：

- ✅ 值得学：**判断/复盘/复利**叙事；盲预测留底；对标冷启动；一次一个的选题对话；cadence/buffer。
- ❌ 不要照搬：「预测会爆」话术；用同一批样本自训自验还叫自进化；等权 rubric 当科学。
- ⚠️ 社区共识倾向：**复盘记账有价值，流量预测要降调**。

## 3. 市场同类（按用户主任务拆开）

### A. 「不知道发什么 / 选题」
| 产品 | 做法 | 形态 |
|---|---|---|
| cheat-seed | 用户给经历 → 深挖角度 → 1 个 draft | Agent Skill |
| CreatorPilot Niche Analyzer | 60s 给 3 个子 niche + 定位句 + 竞争/受众 | SaaS |
| 91运营/小红书选题系统 | 闪念/对标爆文/热点 → 选题池 | 教程/工作流 |
| XHSPlus | 爆款笔记一键分析、找内容空位 | 浏览器插件 |

### B. 「这条值不值得做 / 发前判断」
| 产品 | 做法 | 差异 |
|---|---|---|
| **PreViral** | 创意阶段 0–100 分，10 框架 × 58 niche × 5 平台；**公开 track record** | 发前过滤器，强调可核验预测记录 |
| cheat-score/predict | 个人 rubric 打分 + 盲预测日志 | 不靠全球平均，靠你的历史 |
| vidIQ / TubeBuddy | 事后分析为主（PreViral 自己对比说它们 look backward） | 研究/SEO 向 |

### C. 「怎么持续成长 / 路径」
| 产品 | 做法 | 差异 |
|---|---|---|
| **cheat-on-content** | 单账号判断力复利（rubric 进化） | 个人「判得更准」OS |
| **CreatorFlowX** | 上传尸检 → 对手 → 机会 → 下一条 | 频道相对诊断链 |
| **Creator Pioneer** | niche×变现地图 → 周计划 → 脚本 | TikTok 增长策略 |
| **Zentoko** | 机会雷达 → 定位 → 内容 → 分发 → 转化 → **组合复盘** | 把账号当「投资组合」的 niche 品牌 OS |
| Twin in Bio | 创作者「判断层」产品化 | 变现/导购侧 |

### D. 中文语境关键论断（2025–2026）
- 小红书：从流量思维 → **产品思维 + 搜索思维**；AIGC 后「**真实性护城河**」最值钱。
- AI 定位：副驾驶/创意助理，**人在环路**；纯 AI 稿会被治理与用户疲劳双杀。
- 工具链竞争力从「会用 AI」迁到「**流程/判断系统设计**」。

## 4. 与 TopicAI 现状的错位

| 现状（ContentProject / 内容页） | 用户真实主任务 | 错位 |
|---|---|---|
| 真实经历 → 五阶段项目 → 观察窗 | 找到**自己想发的** | 从「有一条经历」起步，缺「找/选/定位」 |
| 项目生命周期（intent→…→settled） | 选一条**路径**并发展 | 有单条实验，**无路径/赛道/人设层** |
| HumanGate + 表单 + next_action | 发一条并知道有没有用 | 门禁表单过重，「有没有用」被拆成快照/盲评/观察/规则… |
| AI：推断意图、生成候选、编排动作 | AI 判、帮你长判断力 | AI 写/推太多，**判与复盘不够锐** |
| 单项目打点 | 复利、公式进化、对标 | 缺 rubric/对标/组合视角 |

## 5. 候选路径（四选一）

| # | 路径 | 内容 | 代价 | 建议 |
|---|---|---|---|---|
| **P1** | **直接集成 cheat-on-content 思路** | 产品 UI 包一层其方法论（选题对话/盲预测/复盘/rubric），数据仍在 TopicAI | 方法论强、UI/多形态要自建；需避其 overhype 与过拟合坑 | ★★★★ |
| **P2** | **自建「路径 + 判断」产品层** | 重定模型：`路径/人设` 在 `内容` 之上；内容页 = 待决队列 + 对话/产物；复盘进路径 | 工作量大，但贴你主任务与差异化 | ★★★★★（若要产品主权） |
| P3** | **只借鉴市场，不碰校准循环** | 做「找想发的 + 发出去」轻量闭环，成长靠用户自己 | 好做，但「持续发展」空心，易被写作工具淹没 | ★★ |
| P4** | **暂不重做内容页** | 只修 F11/F12/F5 等体验债 | 最便宜，主任务错位仍在 | ★（不匹配你的方向） |

### 两两对比（P1 vs P2）

| 维度 | P1 搬方法论 | P2 自建路径+判断 |
|---|---|---|
| 「找想发的」 | seed 对话可借 | 需要产品化选题/定位 |
| 「发一条」 | 简化为预测+发布登记 | 可与左对话右产物合并 |
| 「选路径」 | **弱**（单账号 rubric） | **强**（路径/赛道/人设一等公民） |
| 「持续发展」 | **强**（复盘复利） | 强（路径上的组合复盘） |
| 与现有 ContentProject | 冲突面大（阶段/观察窗） | 可 additive 演进 |
| 风险 | 社区已骂预测虚高 | 范围大，要砍 MVP |

## 6. 分析结论（供拍板）

1. **主任务必须升维**：从「单条内容项目」升到「**路径（想成为谁/发什么/怎么长大）× 内容（这一条）× 判断（值不值/准不准）**」。
2. **市场空位**：生产工具过剩；「发前判断 + 发后复盘 + **个人公式复利**」话题热但产品化差（skill/SaaS 两极）；**中文创作者的路径选择 + 真实性**几乎没产品做好。
3. **cheat-on-content 可学方法、慎学话术**：盲预测留底、对标冷启动、一次一选题、复盘对账值得进 TopicAI；「预测会爆/自进化」不要抄。
4. **TopicAI 差异点应放在**：真实经历/真实性 + 路径选择 + 可撤销人拍板（已有宪法）+ **诚实的判断复利**（不吹预测）。

## 7. 尚缺证据（不要假装有）

- 中国小红书/公众号创作者为「选路径」付费的意愿与定价——未调研。
- 「一次一个选题对话」是否优于候选池——cheat-seed 默认如此，但无独立数据。
- 观察窗/慢速实验在短视频节奏下的留存——TopicAI 自有假设，未被市场验证。
- PreViral 的 track record 真实预测准确率——未逐条核验。
