## 5. 「是否走偏」验证（对照市场与旧红线）

| 检查 | 结论 |
|---|---|
| 是否违背「AI 只提议」 | 否；决策卡保留 |
| 是否违背「不编造/可溯」 | 否；证据链继承 |
| 是否滑向「预测爆款」 | 新方案否；A 代曾有，已剥离 |
| 是否变成追热点工具 | 需 C1 拍板；默认否 |
| 是否丢掉异步省力价值 | **有风险**（C3）——建议对话主链 + 后台预产 |
| 是否漏掉你点名的素材/剪辑 | **是（已列 G1–G3）** |
| 发展定义是否空心 | 需 G5/G7 补上「可感知变准」 |

## 6. 建议的继承策略（一页纸）

| 动作 | 内容 |
|---|---|
| **继承** | HumanGate、证据/素材/溯源、发布检查、Intent 三型、unknown 合法、导出删除、手动发布、Companion 不遮挡、黄金路径测试 |
| **改造** | 表单→对话/决策卡；观察窗→对账提醒；规则/观点/系列→公式笔记；异步拾取→可选加速；反馈权重→提案制进化 |
| **新增** | 路径画像、去 AI 味、bet 留底、准/偏摘要、素材规划/匹配/剪辑（深度待定）、对标拆解、探索位 |
| **废弃** | 模板假 AI、CTR/播放预测、假热点、团队 MCN、四专业面板独立页、假状态文案 |
| **待拍** | C1 热点、C3 主路径、C4 视频深度、G10 形态 |

## 7. 仍缺证据（勿假装有）

- 用户对「异步挑稿 vs 对话共创」的真实偏好
