## 0. 一句话

主任务**方向对、但不够完整**：要从「找想发的 → 发 → 选路径 → 发展」升级为  
**「在路径上持续发自己认的东西，并越判越准」**——补上**身份/画像、去 AI 味、发前检查、发后归因**四块，首期不做自动多平台发布。

---

## 1. 主任务校验（对不对 / 缺陷 / 缺口 / 有无走偏）

**你定的主任务**：找到自己想发的东西 → 发一条自己想发的东西 → 选择一条合适路径 → 持续发展。

| 判定 | 说明 |
|---|---|
| ✅ 方向对 | 市场从「量产内容」转向「判断力 + 真实性」；与 cheat-on-content「判得更准」、小红书「真实性护城河」一致 |
| ⚠️ 缺陷 A：只靠「想」不够 | 「想发 × 能发 × 有人看」三交集才是可持续选题；纯「想」会自嗨，纯「热点」会空心 |
| ⚠️ 缺陷 B：「路径」层级含糊 | 路径是**月级**（我是谁/发什么/怎么长大），内容是**条级**；混在一条流水线里会做成「项目表」而不是「路径」 |
| ⚠️ 缺陷 C：「持续发展」未定义 | 没说清是涨粉、收入、技能、还是判断力；不同定义产品完全不同 |
| ❌ 缺口 1：身份/画像 | Easel 的 `profiles/{identity,audience,style,platforms,preferences,memory}` 是路径的可执行形态；我们现在没有 |
| ❌ 缺口 2：成稿人味 | 去 AI 味是「发得出去」前提；你要的**内嵌无感**，目前完全缺失 |
| ❌ 缺口 3：发前质量门 | 敏感/版权/平台检查（Easel 发布层）；现在是表单，不是门禁 |
| ❌ 缺口 4：发后归因 | 「知道有没有用」被拆成观察窗/快照/盲评，用户感知是繁琐，不是洞察 |
| ⚠️ 走偏风险 | 若做成「又一个 AI 写作/热点工具」会撞车；若做成「流量预测」会被社区打脸（cheat-on-content #71） |

**修正后的主任务（建议拍板用这句）**：

> **在选定路径上，持续发「自己认的东西」；系统帮我想、写得像人、发前把关、发后说清哪里准/哪里偏，让我越判越准。**

## 2. 本轮深挖结论

### 2.1 ZJU-REAL/Easel（~3.4k star，Apache-2.0）— 最重要参考

| 维 | 事实 |
|---|---|
| 定位 | 私人、持续进化的社媒运营助手：发现 → 策划 → 创作 → 发布 → 归因 |
| 架构 | OpenClaw Agent + **账号画像 Profile** + **113 个 Skill** + 真媒体工具 + 产物归档 |
| 五层 | discover / plan / produce / publish / attribute |
| 画像 | identity / audience / style / platforms / preferences / memory（跨会话） |
| 去 AI | 文案层「去 AI 感改写」；视觉层 `anti-ai-slop.md`（反例清单 + 自查） |
| 发布 | 小红书/抖音/快手/知乎/B站/视频号/公众号；**明确警告小红书自动发布有风控** |
| Skill 规范 | SKILL.md&lt;200 行 + references 按需 + scripts 真执行；三层加载控 token |
| Prompt 栈 | SOUL（人格）→ AGENTS（编排）→ CONTEXT（路径）→ SKILL（按需） |

**可借**：画像即路径落地、五层工作流、去 AI 内嵌、发前检查、归因回写画像、Skill 原子化。  
**不照搬**：113 skill 大而全、OpenClaw 强绑定、自动多平台发布（首期不做）。

| Easel `anti-ai-slop` | — | **视觉** AI 味反例清单（蓝紫渐变/玻璃拟态/emoji 图标…） |

**产品化结论**：成稿默认过一道**中文人话化**（保事实、不删判断、可关）；卡片/封面同步走视觉反 slop 规则；**用户无感**（不出现「去 AI 味」按钮，只出现在稿更像人）。

## 3. 社区真实声音（不限中文）

### 3.1 吐槽（真实痛点）

| 来源 | 信号 |
|---|---|
| r/ContentCreators「cancelled 90% of my AI subscriptions」 | 订阅堆叠更费事；**评判标准应是「是否减少返工次数」**，不是 demo |
| r/generativeAI「$1,000 on AI video tools」 | **迭代成本才是瓶颈**；credits 定价的是「犯错」不是「结果」 |
| cheat-on-content #71 | 预测流量 overhype；**复盘记账才有复利**；自训自验不可信 |
| 小红书方法论文章 | 纯 AI 稿被治理+审美疲劳双杀；**真实性/人在环路**才是护城河 |

### 3.2 付费意愿（间接证据，非定价实验）

| 信号 | 含义 |
|---|---|
| 愿付：直接绑收入/省时/减返工/防风控 | 首期价值主张要落在「少返工 + 判得准 + 发得出去」 |
| 不愿付：重复能力、只用到 20%、订阅内卷 | **不要做大而全工具箱**；一条主路径打穿 |
| 流失首因：「用得不够」 | 产品要**轻介入、高频自然用**（待决队列/对话），不是每周来填表 |
| 去 AI 味类 skill 免费开源火爆 | 单独卖 humanizer 很难；**应内嵌进创作闭环**（与你判断一致） |

**结论**：主任务有真实需求；卖点不能是「AI 帮你写更多/预测爆火」，应是  
**「发得出去 + 少返工 + 个人判断复利」**。

## 5. 建议的产品落点（对齐后展开设计）

```
路径（Profile：我是谁·发什么·边界·节奏·记忆）
  └─ 内容（想发的 → 对话成稿[内嵌人话化] → 发前门 → 登记发布）
        └─ 判断（盲 bet → 对账 → 你准/你偏 → 写回路径）
```

- **内容页**：今日待决 + 项目屏（左对话右产物）  
- **路径页**：画像卡 + 红线 + 节奏 + 公式笔记（从判断回写）  
- **用户无感能力**：去 AI 味、事实保真、来源可溯、检查门

## 6. 风险与证据边界

| 风险 | 缓解 |
|---|---|
| 「想发的」自嗨、没流量 | 选题=想×能×有人看；对标与热点只作参照 |
| 路径做成空洞定位问卷 | 画像要写进每次生成与检查（Easel profile 注入） |
| 去 AI 味误伤原意 | 转 shuorenhua 三档边界：保事实/不删判断/长文保守 |
| 复盘变填表（重蹈观察窗） | 对账≤2 个数 + 可跳过；AI 写「准/偏」草稿 |
| 付费意愿证据不足 | 再调研补用户原话与竞品定价；先定价值主张 |

**尚缺**（勿当已有）：真实用户对「路径」付费的直接访谈；Easel 生产环境稳定性；去 AI 味在小红书场景的通过率数据。

## 8. 垂直 Agent 架构（2026-10-11 你已确认）

> 参考：Hermes Agent（自进化/双记忆/技能=程序性记忆）、OpenClaw（harness 与技能分离）、Pi（工具循环）、Easel（垂直画像驱动）。
> 原则：**人只负责输入和决策**；AI 承担其余并**逐步进化**；我们是**内容创作垂直 agent**，不是通用 harness。

### 8.1 已拍板（5 点）

| # | 结论 |
|---|---|
| A1 | 人机分工 = **人只输入 + 决策**；起草/检查/对账/沉淀提议归 AI |
| A2 | **双记忆**：路径画像（≈USER）+ 判断记忆（≈MEMORY）；**写入须人确认**；有容量、要取舍 |
| A3 | 进化只做 **规则/公式/提示词** 级，**不做模型微调** |
| A4 | Harness 首期**内嵌轻量工具**；OpenClaw/Pi 类执行器**后接**、产品无感 |
| A5 | 垂直技能骨架固定四层：**发现 / 成稿 / 门禁 / 归因** |

### 8.2 分层

```
人：输入（想法/经历/素材/对账数） + 决策（点头/改字/否决/收经验）
产品：今日待决 · 对话+产物 · 决策卡 · 内嵌去AI味（无感）
Agent：编排 + 垂直技能库 + 双记忆 + 进化回路
工具：OpenAI 兼容模型 + 检索/检查/对账/素材（后期可换 harness）
```

### 8.3 进化回路

输入 → AI 产草稿/提议 → 人决策 → 发后对账 → AI 准/偏 → **提议**改公式/画像 → 人「收」才生效 → 下次自动带上。  
学习信号：决策、改字 diff、对账偏差、跳过原因。防过拟合：规则变更对历史样本回放；**不吹预测准确率**。

### 8.4 与现有 AI 能力的去留

| 保留并收进技能 | 阶段 |
|---|---|
| 意图推断、候选生成、编排、字段建议、发布检查、盲评、周复盘 | 0→1 收进四层技能 |
| 证据/素材/溯源、HumanGate、AITrace | 全程红线/审计 |
| 去 AI 味、发前一键修、bet 留底、准/偏摘要 | 1 新增（无感） |
| 路径画像 + 判断记忆 + 公式笔记 | 2 |
| 进化回路（人确认后写入） | 3 |
| OpenClaw/Pi 等执行器对接 | 4 可选 |

### 8.5 铁律（写入产品宪法级）

1. AI 只提议，四决策人工拍板（发布/长期经验/隐私/删除）  
2. 不编造事实；来源可溯；决策可撤销  
3. 记忆/公式变更默认提案制，**人确认才生效**  
4. 不做「预测会爆」叙事与自动发文（多平台发布后置）
