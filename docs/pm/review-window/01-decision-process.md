# 决策简报 + 流程契约（pilot11，D1）

## 决策简报

- **问题**：周复盘页面把 60 天数据标成「本周对照」，用户无法按周理解，复盘类指标口径不成立。
- **证据**：E1——`ReviewPage.tsx` 的 `listWeekly(60)` vs 产品方案「本周全部已发内容」vs 后端 `days=7` vs `feature-inventory.md` 歧义项。
- **方案**：前端双窗口取数（7 天本周 / 60 天欠对账），文案与测试同步。
- **成功指标**：本周对照窗口正确率 100%；欠对账 8/60 天边界用例通过；请求数 = 2；构建/测试绿。
- **kill criteria**：若 7 天窗口导致「本周对照」长期为空且用户要求改自然周 → 停车改方案；若实现需要改后端接口签名 → 回 RG1 重审。
- **被接受风险**：多一次请求；「本周」= 滚动 7 天（U1 显式记录）。
- **决策**：做（T0/D1）；决策人：用户（项目所有者）；日期：2026-10-31。
