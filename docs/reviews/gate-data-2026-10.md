## 5. 12-15 / 2027-01-31 要回答的问题（预注册，不是新阈值）

**每道门用同一组问题审**（证据不足就写“不足”，不许用印象替代）：

1. 过去窗口内，它是否**真实拦下过 blocking/major**？实例是什么（change + finding ID）？
2. 它的执行成本（轮次/时长/记录）与替代方案相比如何？
3. 它是否**经常 not-run/bypass**？若如此，问题是门太重还是执行者绕过？
4. 若删/降级它，**风险由谁兜底**（另一道门/测试/CI/发布回滚）？
5. 有没有“为了过门而补文档”的迹象（记录 ≠ 决策）？

**候选处置的证据门槛（预注册）**：

- **降级**：连续 ≥2 次同类变更中该门 0 实质发现（B/M），且替代措施已在真实变更中验证；仍保留清单/抽查。
- **删除**：降级观察一个窗口后仍 0 实质发现 + 风险承接明确 + 用户书面接受；**不删安全/发布/数据相关门**（RG2/RG3/OG0 至少保其一）。
- **升级/加门**：本季**不允许**（D9 ≤15、D2 不新增）；只有出现真实事故且现有门无法承接时才提案，走“加一删一”。

> 结论仍以季度决策记录为准；本表只提供证据，不预判结果。
