## 二、我的 → 创作设置：说明文字与字段标签重叠（已修）

量化结果：
- 卡片说明 `<p>`：y 401.4 → **422.9**
- 第一个字段的浮动 `<label>`「每周发布目标 *」：y **413.9** → 430.0

两者**重叠约 9px**——标签压在说明文字上。根因是卡片头部与紧随其后的表单之间没有任何间距。
修法：只在该组合出现时加间距（`.operations-row-header + .MuiStack-root`），不带表单的纯标题行不受影响。
修完复测：重叠对数为 0。

## 三、机会 → 工具行：九个控件混在一个换行流里（已修）

390 实测：状态按钮、「筛选」开关、两个筛选下拉、两个动作按钮同处一个 flex 流，
按"能塞多少塞多少"换行，结果「筛选」被夹在状态按钮和主按钮之间，读起来像一个孤立的词。

修法：分成**两个各有单一目的的组**——状态筛选组 / 操作组；宽屏同排右对齐，
窄屏各占一行（实测：1280 两组同在 y=118；390 分别 y=98 与 y=197）。
两个下拉在窄屏折叠到「筛选」之后是**原有设计**，未改动；不清晰的是它周围的排版。
