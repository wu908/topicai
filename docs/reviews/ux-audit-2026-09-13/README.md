## 三、AI-native 设计的优点（迭代中必须保留）

1. **意图先行**：从"模糊想法"开始，不要求完整 Brief。
2. **素材最小授权**："它只基于这个写，不编"、分段确认前先确认素材授权、家人入镜标记私密。
3. **版本安全**："系统不会覆盖已确认的版本，也不会自动发布"、"你确认过的内容不会被自动改写"。
4. **事实溯源**：候选段落标"依据：相关内部记录"，写作提醒明示"AI 只使用当前项目中已确认的信息"。
5. **信任阶梯**：每项能力累计 3 次被采纳才解锁自动化；信任面板每一项可收回。
6. **反表演性进度**：里程碑"只在真实行为满足时点亮"。
7. **不虚构**：候选正文占位"写不出的条目直接删除；当前版本不会虚构缺失经历"。
