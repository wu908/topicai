## 一、内容页（本次重点）

### 1. 空态与入口
- 现状：快速开始 / 去路径 / 贴参考 / 直接输入，4 个并行入口（报告 §3.1）。
- 方向 A（推荐）：**一个主 CTA「开始第一条」**（输入一句话）；"不知道怎么开始？"折叠区放盘点经历 / 贴对标。
- 方向 B：向导式 3 步（先选方向 → 再选形态 → 写一句）。
- 方向 C：保留现结构，只改文案与视觉主次。
- 影响：A 改动小、心智清楚；B 更"新手友好"但步骤更长；C 不解决根本问题。

### 2. 列表
- 方向 A（推荐）：三组（**想发的 / 在途 / 已发**）+ 行内"下一步：<动作> [按钮]"；统计只留一行；`需要我` 只做筛选，不做行内标签。
- 方向 B：保持平铺，只加"下一步"按钮与排序。
- 方向 C：看板（三列拖拽），适合重运营，但对新手偏重。
- 行的最小信息：AI 命名/标题 + 形态/状态/最近动作 + 下一步按钮 + "为什么需要我"一行。

### 3. 项目屏
- 方向 A（推荐）：**单条人话流程条**：想清楚 → 找素材 → 写初稿 → 发前检查 → 观察；当前步高亮，旁边一句"现在做：…"；右栏只留页签。
- 方向 B：保留两条但都可点击切阶段（把 span 变按钮），解决"看起来能点却点不动"。
- 方向 C：去掉阶段条，只在顶部显示"下一步 + 按钮"。
- 配套：过程页去掉硬编码"路径：效率实验·未偏离"；"素材已挂"只算本条关联素材（bug 已修）；"项目助手 · 项目助手"已修。

### 4. 稿页
- 方向 A（推荐）：**标题 + 正文都可编辑**；保存状态常驻（保存中 / 已保存 hh:mm / 未保存）；提供「AI 起草」「润色」入口；没有第一版时显示"先完成上面的确认卡"。
- 方向 B：正文保持只读，AI 整段重写，用户只审稿。
- 方向 C：点"编辑"弹独立编辑器（移动端友好，但多一层）。
- 依赖：需要后端支持改标题（当前版本只有 body_text）——若选 A，需要加一个 `title` 更新能力（接口小改）。

### 5. 发布包 / 视频包
- 方向 A（推荐）：**前置条件清单 + 快捷动作**：
  - 发布包：① 确认方向 ② 有第一版稿 ③ 运行发前检查 → 每项给状态和按钮；
  - 视频包：缺口清单每行加"去素材匹配"，一键把素材关联到本项目。
- 方向 B：只改文案说明，不动结构。
- 方向 C：拆成独立页面（成本高，暂不建议）。

### 6. 移动端
- 方向 A（推荐）：底栏 4 + 更多；筛选 chips 横向滚动；浮动 AI 球可收/避开内容；项目屏抽屉式右栏。
- 方向 B：整体缩小字号/间距。
- 方向 C：移动端只保留"今日 + 内容"两条主链路。
