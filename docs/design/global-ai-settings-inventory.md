## 文案规则（设置页同样适用）

- 每项：**做什么 + 会怎样 + 副作用**  
- 危险项（清空、删号）写后果  
- 未上线能力标注「规划中」，不装可用

## 修订（2026-10-11）：设置做成整页，三块分开

**入口**：侧栏「设置」+「我的 → 打开设置」（整页，不是悬浮窗内设置）。

| 分区 | 管什么 | 与另一 AI 的关系 |
|---|---|---|
| **产品与创作** | 默认形态、周目标、发前检查、对账提醒 | 与 AI 无关 |
| **全局 AI** | 名称/头像、agent.md 全局指令、模型接口、灵感快捷键、**全局操控范围** | 悬浮球助手 |
| **项目助手（内容页）** | 名称/头像、agent.md 项目指令、**去 AI 味**、起草语气 | 只影响内容页对话与成稿 |
| **记忆** | 路径画像、判断记忆、写入方式 | 两 AI 共用，写入策略一致 |
| **隐私** | 素材默认级、导出、删号 | 全站 |

**规则**：全局 AI 与项目助手的名称、头像、agent.md、语气**分开存**；模型接口通常共用一套，可进阶双配置。

### 头像能力（2026-10-11）

| 能力 | 说明 |
|---|---|
| 换色 | 光晕色快选（保留） |
| **上传图片** | JPG/PNG，建议正方形；圆角裁切展示 |
| 作用范围 | **全局 AI 头像**与**项目助手头像**各自上传，互不覆盖 |
| 默认 | 可一键恢复默认 |
| 存储 | 原型本地预览；实现阶段存用户资源并遵守隐私默认私密 |
