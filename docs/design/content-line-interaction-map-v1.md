## 10. 全局 AI 面板

| 控件 | 行为 |
|---|---|
| 名称输入 | ✎ 改名；头像字同步 |

# v1.1 修订（经第一性原理审查后）

> 详见 `content-line-interaction-review-v1.md`。以本节覆盖上文冲突项。

## 修订 A · 快速开始（轻→重）

| 步 | 行为 |
|---|---|
| 1 | ⊕ 弹层：「一句话」输入 |
| 2 | 选择：**只记下来**（→ 内容·想发的）或 **立成内容**（→ 项目屏） |
| 3 | 全局 AI 速记默认走「只记下来」；说「做成一条」才立项 |

## 修订 B · 删除「完整工作台」

兼容期若保留：默认隐藏；不得已露出须标「旧版 · 即将移除」。

## 修订 C · 跳转必带锚 + 到达提示

| 从 | 到 | 锚/提示 |
|---|---|---|
| 今日·候选 | 项目·稿+确认卡 | 「已为你打开：确认候选」 |
| 今日·公开 | 项目·确认卡 | 「已为你打开：公开范围」 |
| 今日·预产 | 项目·视频包 | 「已为你打开：视频包」 |
| 今日·对账 | 复盘·欠对账并聚焦 | 「已为你打开：对账」 |

## 修订 D · 否决不死路

否决后选项：**改稿** / **换建议** / **暂时搁置**（回今日「等你定」）。

## 修订 E · 设置生效模型

- toggle / select / 名称 / 头像 / 快捷键：**即改即存** +「已保存」轻提示  
- agent.md 长文本：显式「保存」  
- 危险项（清记忆、删号）：二次确认  

## 修订 F · 状态闭环

| 情况 | 行为 |
|---|---|
| 锁 bet 后改稿 | 提示更新判断或保留旧 bet |
| 对账「跳过」 | 标 unknown；今日不催；复盘可见「已跳过」 |
| 删除有引用的素材 | 警告引用项目 |

## 修订 G · 项目屏入口

本条栏增加「**本条助手设置**」→ 设置页「项目助手」段（聚焦）。

## 修订 H · 全局 AI 对象级操作

支持「打开××那条」；仅进入项目对话，**不直接改正文、不代拍板**。

## 职责速查（终版）

| | 全局 AI | 项目助手 |
|---|---|---|
| 速记灵感 | ✓ | 仅本条备注 |
| 改稿正文 | ✗ | ✓ |
| 确认卡 | 打开待你拍 | 出卡，人点 |
| 设置 | ✓ 预览后改 | ✗ |
| 四决策 | ✗ | ✗ |
