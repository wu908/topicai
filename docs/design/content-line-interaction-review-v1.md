# 交互地图 · 第一性原理审查与修订 v1.1

> 方法：问「用户此刻任务是什么 → 点这个会不会达成 → 会不会懵」。  
> 输入：你的主任务（找想发的→发→路径→发展）、人只输入决策、全局 AI=速记+操控、双 AI 分离、文案无歧义、Web 先跑通。  
> 结论：**不改会翻车的 3 处 + 该补的 4 处**；已回写 `content-line-interaction-map-v1.md`。

---

## 1. 总原则（用来裁决对错）

| # | 原则 | 裁决问题 |
|---|---|---|
| P1 | 一步只服务一个任务 | 跳转后是否仍在同一任务里？ |
| P2 | 轻进重出 | 「想发的」应比「项目」更轻；不该一点就掉进重流程 |
| P3 | 可预期 | 用户能否预判「点完会到哪」？ |
| P4 | 可逆、可解释 | 否决/跳过/改之后有没有「然后呢」？ |
| P5 | 双 AI 不越权 | 全局不代改稿；项目不聊全站 |
| P6 | 设置：改了就懂生效 | 不出现「我到底存没存」 |

---

## 2. 判定：会出问题的跳转 / 按钮

### ❌ X1「快速开始」一点就进项目屏（过重）

| | |
|---|---|
| **用户任务** | 可能只想**记一笔**，未必要立项 |
| **问题** | 与全局 AI「灵感速记」双入口打架；跳到项目像被推入长流程 |
| **改法** | 快速开始 = **轻创建**：输入一句 → 选「只记下来」或「立成内容」；仅后者 → 项目屏。全局 AI 落点：**只记下来 → 想发的** |

### ❌ X2「完整工作台」（语义不明 + 开倒车）

| | |
|---|---|
| **问题** | 与「废表单、对话+产物」矛盾；用户不知点进去会多出什么 |
| **改法** | **删除**。若兼容期必须保留：改名「更多工具（旧版）」并标「即将移除」；默认不露出 |

### ❌ X3「去处理」是否总落在对的地方

| | |
|---|---|
| **问题** | 候选/公开/预产 落点若只是「进项目」，用户还要自己找 |
| **改法** | 必须带锚：候选→**稿+确认卡**；公开→**确认卡**；预产→**视频包**；对账→**周复盘·欠对账并聚焦**。到达后**顶部一句**「已为你打开：××」 |

### ⚠️ X4 确认卡「否决」后只有记录

| | |
|---|---|
| **问题** | 用户会想「那接下来呢？稿子还算吗？」 |
| **改法** | 否决后必出**下一步**：改稿 / 换建议 / 暂时搁置（状态「待你定」仍在今日） |

### ⚠️ X5 设置「保存」模型未定

| | |
|---|---|
| **问题** | 「改完点保存」还是「改完即存」不清 |
| **裁决** | **即改即存**（toggle/select/名称/头像）+ 轻提示「已保存」；**仅** agent.md 长文本用「保存」；危险项二次确认 |
| **理由** | 符合 P6；移动端全局 AI 才好代办「帮我改设置」 |

## 3. 逻辑洞（路径不闭环）

| # | 洞 | 补法 |
|---|---|---|
| L1 | **bet 锁定后改稿** | 改稿→提示「判断仍对应锁定稿」→「更新判断 / 保留」 |
| L2 | **对账「跳过」后** | 标 unknown，仍可写公式；今日不再催；周复盘可见「已跳过」 |
| L3 | **全局 AI「新建/跳转」缺对象级操作** | 支持「打开番茄钟那条」；列表检索→进项目；不能改稿正文（P5） |

---

## 4. 用户会懵的文案/预期（补「到这你会看到什么」）

| 点击 | 用户可能问 | 界面应答 |
|---|---|---|
| 去处理 | 我要干什么？ | 一句任务标题 + 预计时间（已有则保持） |
| 粘贴/链接解析 | 解析失败呢？ | 保留原文 + 「解析未完成，可手填」 |
| 上传头像 | 会公开吗？ | 「头像仅用于界面展示，默认不公开」 |
| 收下公式 | 会不会改我历史？ | 「只影响以后，不改已发内容」 |
| 全局操控预览 | 会不会乱改？ | 「不会自动执行发布/删除」 |

---

## 5. 职责边界（P5 再拧紧）

| | 全局 AI | 项目助手 |
|---|---|---|
| 记灵感 | ✓ 主场景 | 可记到**本条**备注 |
| 改稿正文 | ✗ 可「送去项目里改」 | ✓ |
| 确认卡拍板 | ✗ 只可**打开**待你拍 | 仅出示卡片，人点 |
| 改设置 | ✓（预览后改） | ✗ |
| 对账填数 | ✓ 可代办 | ✓ 本条 |

设置页从**项目屏**加入口「本条助手设置」→ 滚到「项目助手」段（否则用户找不到）。

---

## 6. 主路径（修正后，从第一性原理）

```
灵感（轻）→ 想发的 → 立项（可选）→ 项目：对话+产物
    → 确认卡（表达/公开）→ 登记发布 → 对账 → 准/偏 → 路径/公式
全局 AI：随时速记 / 跳转 / 代办非四决策
设置：产品 + 全局 AI + 项目助手（即改即存）
```

**砍掉**：完整工作台、无锚跳转、否决死胡同、保存模型含糊。

---

## 7. 对交互地图的补丁（摘要）

1. 快速开始改为「记下 / 立项」二选一  
2. 删「完整工作台」  
3. 所有跳转带锚 + 到达提示  
4. 否决必给下一步  
5. 设置即改即存  
6. bet/对账/跳过闭环  
7. 项目屏 → 本条助手设置  
8. 全局 AI 对象级「打开某条」
