## 0. 设计原则（六条）

1. **人只输入和决策**——每个屏幕先问：哪段是给人拍板的？其余让 AI 消化。  
2. **对话推进，产物可改**——左边说话干活，右边成品上手改。  
3. **一种确认卡**——事实/意图/发布/经验同构，不弹窗连环。  
4. **今日是唯一驾驶舱**——待决不清就不用打开别的页。  
5. **诚实**——提议标来源；无预测数字；读数中/无数据要说人话。  
6. **Lumen 约束下做信息密度**——玻璃卡、发丝线分组；能用留白就不塞卡片。

## 2. 今日（驾驶舱）

### 2.1 布局

```
┌ 今日 ──────────────────────────────────────────┐
│ 你好 · 本周：待你定 3 · 欠对账 2 · 在途 1      [快速开始] │
├────────────────────────────────────────────────┤
│ 等你定（3）                                      │
│  ┌ 决策卡 ───────────────────────────────────┐ │
│  │ 番茄钟…  ·  要你确认候选                  │ │
│  │ 为什么现在：AI 已备好 2 版，等你拍板       │ │
│  │ [去处理]  [稍后]  [问它]                   │ │
│  └───────────────────────────────────────────┘ │
│ 欠对账（2）…  ·  路径提醒（1）…                 │
└────────────────────────────────────────────────┘
```

| 元素 | 行为 |
|---|---|
| 顶部计数 | 只读、可点筛选队列段 |
| **快速开始** | 主 CTA（全页唯一 contained primary） |
| 决策卡 | 进项目屏对应锚点；「稍后」写 defer 原因（可选预设） |
| 空态 | 「今天没有等你的事」+ 去想一条 / 看素材 |

**禁止**：三个项目列表并排；假输入框；spinner 代替骨架。

## 3. 内容列表

### 3.1 分段

`想发的` / `在途` / `已发` + 视图 chips（全部 / 需要我 / 观察中）沿用「谁在等谁」语义。

### 3.2 行（沿用 V3 密度，收「下一步」）

- 阶段点/进度 · 标题 · 形态（图文/视频）· 人话下一步 · 时间 · 需要我旗标  
- 行点击 → 项目屏；不进多级详情页（≥840 双栏预览可保留，或直接进项目屏——**取「直接进项目屏」**，减少一层）

### 3.3 搜索与筛选

搜索标题/形态；chips 四态；**不做** facet（列表常超一屏后再议）。

## 4. 项目屏（核心）

### 4.1 布局（≥840：双栏；&lt;840：堆叠）

```
┌ 路径语境条：路径「租房改造」· 偏离提示 ──────────────┐
├─────────────────────┬───────────────────────────────┤
│ 左 · 对话             │ 右 · 产物                       │
│ AI 消息（提议/问句）   │ [稿] [发布包] [视频包*] 页签    │
│ 用户消息              │ 正文可直接编辑                  │
│ ───────────          │ 素材匹配行（推荐/已用）*         │
│ 内联决策卡            │ bet 一句话 · 对账回填           │
│ 输入泡                │ [打开完整编辑 →] 非必须         │
└─────────────────────┴───────────────────────────────┘
```

### 4.2 对话区规则

| 规则 | 说明 |
|---|---|
| AI 每则消息 = 一个可执行提议或一个短问 | 不长篇说明书 |
| 提议带**来源/置信**轻量标签 | 「根据你 3 条素材」「解读自对标」 |
| 用户改右栏字 → 对话出现「你改了 N 处」回执 | 不打断编辑 |
| 流式/骨架 | 长生成用骨架条，不用整页 spinner |
| Companion 悬浮球 | 可开全局问「它」，**不抢**主对话 |

### 4.3 产物页签

| 页签 | 内容 | 交互 |
|---|---|---|
| **稿** | 正文、标题候选 | 就地编辑；段落旁「重写这段」 |
| **发布包** | 标题/标签/封面建议/检查结论/时机建议 | 检查项可一键修 |
| **视频包**（形态=视频） | 分镜、素材匹配、粗拼预览、字幕 | 采纳/换素材/重拼 |
| **bet / 对账** | 半句 bet、1–2 个数 | 发布后变对账 |

### 4.4 路径语境条

非第四面板：一句「当前路径 + 是否偏离」；点开抽屉改路径或「就这条例外」。

## 5. 确认卡（C5，全局唯一形态）

```
┌ 确认卡 ────────────────────────────────────┐
│ 要你拍板：公开范围                            │
│ AI 建议：可公开（依据：素材你已标 publishable）│
│ [同意]  [改]  [否决]                          │
└─────────────────────────────────────────────┘
```

| 类型 | 字段差异 |
|---|---|
| 事实/素材 | 可逐条源链接 |
| 意图 | 三选项 solve/share/record |
| 发布 | 时机 + 风险摘要 + bet |
| 长期经验 | 变更 diff + 影响范围 |

- 出现在**对话流**或**产物旁**，不弹系统 Dialog（移动端可用全屏抽屉但同一组件）。  
- 未决卡片在今日队列出现。  
- 四决策永远可否决；否决要一句原因（可选预设）。

## 6. 复盘页

| 段 | 内容 |
|---|---|
| 欠对账 | 卡片：标题、提醒、[去对账] |
| 准/偏 | 周列表：bet vs 实际、AI 摘要 1 句 |
| 公式笔记 | 变更提案：diff、[收]/[不收]、回放对比入口 |
| 空 | 「还没有可复盘的」+ 为什么 |

**禁止**：观察窗主状态机；多面板规则/观点/系列操作。

---

## 7. 路径页

| 段 | 交互 |
|---|---|
| 画像卡 | 我是谁/发什么/红线/节奏；AI 可「建议修订」→ 确认卡 |
| **对标** | 贴样本/链接 → 解读（三列：选题/结构/读者）→ **逐条勾选确认** → 写入 |
| 公式笔记 | 只读历史版本 + 当前生效 |
| 探索位 | 当前实验位说明、落选归因列表 |

对标输入：`textarea`（空行分条，**文案写明**）+ 可选「粘贴链接」；解读加载骨架；失败保留粘贴内容（UAT 已有教训）。

## 10. 状态与四态

| 态 | 全局规则 |
|---|---|
| loading | 内容形状骨架；**不**显示空态 |
| empty | 为什么空 + 下一步 |
| error | 人话 + 重试；**保留**已载入数据 |
| data | 正常 |

**项目产出生成中**：产物区骨架 + 对话「正在写…」；可中断。

## 11. 断点

| 宽 | 布局 |
|---|---|
| ≥840 | 今日双栏可选；项目屏左对话右产物 |
| 600–839 | 单栏；产物页签在上或下（默认**对话上/产物下**） |
| <600 | 单栏；确认卡全屏抽屉；底栏避让主 CTA（padding 已有 180 先例） |

---

## 12. 文案与语气

- 短句、具体、可执行；「约 2 分钟」优于「马上」  
- 提议用「我建议…依据是…」；不写「预测你会爆」  
- 错误说原因与下一步；禁 AI 腔排比堆砌  
- 中点 `·` 每行 ≤1；不用破折号当分隔装饰（Lumen）

---

## 13. 关键流验收（交互）

| 流 | 通过标准 |
|---|---|
| 快速开始→成稿→发前→登记 | 全程不进独立表单页；确认卡 ≤3 张 |
| 确认卡否决 | 可否决并留下原因；不出现死路 |
| 对标导入 | 粘贴 3 条→解读→改一条→写入路径 |
| 视频包 | 匹配→粗拼→审→登记 |
| 复盘 | 1 个数或跳过→准/偏→收/不收 |
| 断点 | 390 无横向溢出；主 CTA 不被底栏压住 |
| 诚实 | 无假状态；无 CTR 数字；来源标签可见 |

## 16. 全局 AI（悬浮球）定位补记（2026-10-11）

> 本节为**需求记录**。移动端**本阶段不实现**；web 跑通后再单独设计。

### 16.1 职责（web + 未来移动一致）

| 能力 | 说明 |
|---|---|
| **灵感速记** | 一句话/语音/贴图丢进来，进「想发的」，可不打断当前页 |
| **全局操控** | 用户操作尽量可由该 AI 完成：跳页、开条、改状态、对账、路径修订（仍受 HumanGate） |
| **解释** | 「下一步为什么」、检查结论、准/偏原因 |
| **身份** | 头像+名称**用户可自定义**；与「项目助手」分离 |

### 16.2 移动端（**仅记录，不开发**）

| 规则 | 内容 |
|---|---|
| 首屏 | 打开 App **必须是全局 AI 页**，而不是列表首页 |
| 导航 | 其他页为次级入口（可由 AI 拉出，或底栏少量快捷） |
| 交互 | 语音/文字为主；表单尽量由 AI 对话代办 |
| 边界 | 四决策仍人工拍板；无自动发布 |
| 阶段 | **Web 端跑通并验收后**再出移动设计与实现 |

### 16.3 Web 原型已体现

- 悬浮球 → 全局 AI 面板（灵感输入 + 全局指令）
- 名称/头像可改
- 文案标明与项目助手分工
