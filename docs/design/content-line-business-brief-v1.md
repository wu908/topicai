## 1. 产品定义

### 1.1 主任务（D1）

> **在选定路径上，持续发「自己认的东西」；系统帮我想、写得像人、发前把关、发后说清哪里准/哪里偏，让我越判越准。**

### 1.2 三维模型（D3）

| 维 | 回答 | 载体 |
|---|---|---|
| **路径 Path** | 我想持续发什么？怎么长大？ | 路径画像 + 公式笔记 |
| **内容 Content** | 这一条我想发的是什么？ | 想发的 → 稿 → 发 |
| **判断 Judgment** | 值不值？我准不准？ | bet → 对账 → 准/偏 → 写回路径 |

### 1.3 「持续发展」定义（D2）

**首期 = 判断力与路径清晰度**（我能更准地选题、成稿、复盘；路径更清楚）。  
**不承诺**涨粉、收入、爆款率。

### 1.4 人机契约（已锁）

| 人只做 | AI 做 | 铁律 |
|---|---|---|
| 输入（想法/经历/素材/对账数） | 深挖、起草、改写、检查、对账摘要、沉淀提议 | 只提议不代决 |
| 决策（点头/改字/否决/收不收） | 人话化、溯源、编排、学习信号整理 | 四决策人工拍板 |
| | | 不编造 · 可溯 · 可撤销 |
| | | 记忆/公式写入 = 提案制 |
| | | 不吹「预测会爆」 |

## 3. 用户旅程（条级）

### 3.1 主旅程

| 步 | 用户 | 系统/Agent | 介入次数 |
|---|---|---|---|
| ① 找到想发的 | 说一句想法/经历/闪念 | 技能「发现」：深挖角度（对标/热点仅参照） | 1 |
| ② 对齐路径 | 点头或说「偏了」 | 对照路径画像提示 | 0–1 |
| ③ 成稿 | 改字 / 要求改某段 | 技能「成稿」：起草 + **内嵌人话化** | 1–N |
| ④ 发前 | 写半句 bet + 确认 | 技能「门禁」：检查、一键修、bet 留底 | 1 |
| ⑤ 发布 | 登记链接/已发 | 状态推进（多平台后置） | 1 |
| ⑥ 对账 | 填 1–2 个数或跳过 | 技能「归因」：准/偏摘要 | 0–1 |
| ⑦ 沉淀 | 收 / 不收这条经验 | 提议写入公式/画像（**确认才生效**） | 0–1 |

**目标：一条内容人介入 ≤ 5 次，每次都是点头/改字/半句话；无独立表单页。**

### 3.2 日常（不是条级）

| 场景 | 入口 | 行为 |
|---|---|---|
| 打开产品 | **今日** | 待决：等你定的稿 / 欠对账 / 路径提醒 |
| 随手丢灵感 | 今日/内容快速捕获 | 进「想发的」，不逼立刻写 |
| 看我准不准 | **复盘** | 对账列表 + 准/偏 + 公式笔记入口 |
| 调方向 | **路径** | 画像、红线、节奏、对标、公式 |
| 找旧素材 | **素材** | 引用进稿 |

### 3.3 旅程中的人感目标

- 少迷路（6 入口、今日唯一驾驶舱）  
- 少填表（表单→对话/决策卡/产物编辑）  
- 稿像人（无感人话化）  
- 账清楚（准/偏可核验）  
- 越用越准（公式/画像可感知更新）

## 4. 信息架构（D9 + F1）

### 4.1 导航（10 → 6）

| 一级 | 内容 | 取代 |
|---|---|---|
| **今日** | 待决队列 + 快速开始（含原急稿） | 晨报 + 急稿 + 产出架主体 |
| **内容** | 想发的 / 在途 / 已发；项目屏（左对话右产物） | content + 灵感池 |
| **复盘** | 对账、准/偏、写回提议 | 周复盘 + 校准/观察主路径 |
| **路径** | 画像、对标、公式、红线、节奏 | 我的扩展 + 成长 + starter |
| **素材** | 库 + 引用 + 收件箱捕获入口 | materials（+inbox） |
| **我的** | 账号 / AI 配置 / 导出删除 | 保留瘦身 |

### 4.2 内容项目屏

```
┌ 今日待决 / 内容列表 ─────────────────────────────┐
│ 等你定 · 3 │ 欠对账 · 2 │ 路径提醒 · 1 │ 已沉淀   │
├──────────────┬──────────────────────────────────┤
│ 左 · 对话     │ 右 · 产物                         │
│ AI 深挖/起草/ │ 当前稿（可直接改字）              │
│ 检查/对账     │ 发布包：标题/标签/检查结论        │
│ 决策卡        │ bet / 对账回填                    │
└──────────────┴──────────────────────────────────┘
路径语境条：当前路径 · 偏离提示（非第四面板）
```

### 4.3 入口收容（F2 / F3）

| 原入口 | 去向 |
|---|---|
| 急稿 | 今日「快速开始」 |
| 产出架/灵感池 | 今日待决 + 内容「想发的」 |
| 成长 | 路径 / 我的 |
| Starter 三步 | 路径设定一次 |
| 观点/系列/规则/观察面板 | 路径·公式笔记（冻结独立操作） |
| 收件箱 | 素材·捕获（消化接到内容链路） |

## 5. 功能处置摘要（F5 + 盘点）

### 5.1 核心七件（P0 必达）

1. 路径画像  
2. 素材/证据（溯源）  
3. 想发的  
4. 对话成稿（内嵌人话化）  
5. 发前检查（一键修）  
6. 发布登记  
7. 对账复盘（准/偏 → 写回）

### 5.2 保留的既有资产

- 真实经历优先、不编造、HumanGate 四决策、AITrace、可撤销、来源可溯  
- `/api/v2` 契约与 ContentProject 聚合（additive 演进）  
- 发布检查、盲评思想、周复盘推辞克制（「一次结果不自动改写长期规则」）  
- **对标锚 ReferenceAnchor**（升级为下述规格）  
- G4 下一步同源、骨架四态、悬浮球不遮内容  
- **无指标 unknown 合法**（G9）；三意图分型（G8）

### 5.2b 对标规格（G4，已拍板）

| 项 | 规格 |
|---|---|
| 定义 | **对标账号/作品锚**：你想做成那样；不是热点监控 |
| 输入 | **粘贴样本 + 可选链接解析**；2–12 条；可标 `@账号` |
| 分析（自动） | 选题范围、结构习惯、标题钩子、口吻、节奏；每条结论挂证据编号 |
| 人工 | **解读结果必须你改/否决后写入路径** |
| 不做 | 持续爬号、代运营、抄结构成文、拿别人数据当你基线 |
| 产物 | 路径·对标；反哺选题/成稿/检查 |

### 5.2c 确认卡（C5）

事实/意图/发布/经验等确认合并为**一种确认卡**：在对话或产物旁内联完成；取消多处弹窗连环。四决策语义不变，仅交互收敛。  

### 5.3 删/冻

假 AI 状态、假输入框、重复下一步文案源、未接前端冷 API、四面板独立操作、任何「预测会爆」文案。

## 6. 垂直 Agent 业务接口（产品视角）

### 6.1 四层技能（v1.1 扩）

| 层 | 技能 | 输入（人） | 输出（给 UI） | 人决策点 |
|---|---|---|---|---|
| **发现** | 选题深挖、**对标拆解**、素材缺口规划 | 一句想法/经历；对标粘贴/链接 | 1 个角度提案；对标解读；缺口清单 | 认/否决；**确认解读** |
| **成稿** | 起草、段落改写、人话化、**素材匹配**、视频脚本 | 角度 + 素材 | 稿/段落；推荐素材列表 | 改字/换素材 |
| **产出**（视频） | 粗拼、字幕、封面草稿 | 脚本+素材匹配结果 | 粗剪预览 | 审/重做 |
| **门禁** | 发前检查、一键修、**发布时机**、bet | 稿 + 半句 bet | 检查单、修后稿、bet、时机建议 | 发/不发 |
| **归因** | 对账、准/偏、沉淀提议 | 1–2 个数或跳过 | 准/偏摘要、公式/画像变更提案 | 收/不收 |

> 主路径仍是七步；「产出」为视频支路，不挡图文。

### 6.2 双记忆

| 存 | 例 | 写入 |
|---|---|---|
| **路径画像** | 我是谁、发什么、红线、节奏、风格 | 人设定 + AI 提议修订 |
| **判断记忆** | 公式、准/偏规律、常踩的坑 | AI 沉淀提案，人确认生效 |

有容量上限；满了 AI 负责整理（合并/删过时），不瞎丢。

### 6.3 进化回路

```
人决策 + 改字 diff + 对账偏差 + 跳过原因
        ↓
   学习信号入库
        ↓
 AI 提议：改公式权重 / 改检查规则 / 改提示词约束
        ↓
 历史样本回放对比（防过拟合）
        ↓
 人「收」→ 版本化写入 → 下次生成/检查自动带上
```

### 6.4 无感能力（产品无按钮）

去 AI 味、事实保真、来源溯源、检查门、bet 留底、准/偏计算。

## 7. 与现有系统衔接

| 层 | 策略 |
|---|---|

## 9. 验收口径（业务，v1.1）

| 维 | 指标 |
|---|---|
| 介入成本 | 一条内容人介入 ≤5 次；填字段 ≤2 处（bet + 对账数） |
| 诚实 | 无假输入/假状态；来源可溯；无预测数字 |
| 同源 | 「下一步」唯一文案源；确认卡唯一形态 |
| 闭环 | 七步可回看；视频支路可出粗拼包 |
| 对标 | 结论必带样本证据；须你确认才进路径 |
| 可逆 | 公式/画像可撤销；四决策可拒 |
| 质量门 | 测试覆盖率、lint、类型检查全绿 |

## 10. 风险与边界

| 风险 | 业务缓解 |
|---|---|
| 「想发的」自嗨 | 选题 = 想 × 能发 × 有人看；对标/热点只参照 |
| 复盘又变填表 | 对账≤2 数、可跳过、AI 写准/偏 |
| 去 AI 味误伤 | 保事实/不删判断/长文保守；可关 |
| 进化变成黑盒 | 提案制 + 回放对比 + 变更可见 |
| 范围膨胀 | P5 全部后置；本期不碰自动发布 |
| 旧数据/旧用户 | additive；冻结入口不删数据 |

**尚缺证据**（不在本期假装有）：路径付费访谈、去 AI 味小红书通过率、Easel 线上稳定性。

## 11. 成功画像（产品叙事）

> 我打开 TopicAI，今日只看到「等我点头」的两三件事。  
> 我说一句想发的，它帮我收成角度、写出像我写的稿。  
> 我改两处字，它帮我把关，我打半句赌，发出去。  
> 几天后它告诉我哪里准、哪里偏，我点头它才记住。  
> 一个月后，它比刚认识我时更懂我该发什么——**不是因为我填了更多表，而是因为它替我跑腿、我只拍板。**

## 13. 全局 AI 与移动端（2026-10-11 补记）

**全局 AI（悬浮球）**：灵感速记入口 + 全站操控代理（用户可通过对话完成跳转/建条/推进/对账等，受四决策约束）。头像与名称可自定义。与项目屏「项目助手」**身份与职责分离**。

**移动端（后置）**：首屏必须为全局 AI；其余页面次级。仅在 **Web 主链验收通过后**设计与实现。本阶段只做记录与 web 原型表达。
