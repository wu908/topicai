# 给测试者的一页说明（2026-09-15）

> 用途：由产品负责人转发给 3–5 位测试者（微信/飞书直接粘贴即可）。
> 对应 `docs/ai-native-async-creation-plan-2026-08-29.md` 的 Phase 2 狗粮期（2 周）。
> 三线数据就是这次要收集的东西——下面是它的人话版本。

---

## 这是什么

一个帮你持续产出的工具：**你把素材丢进去，它替你整理成可以发的初稿；发不发、发什么，永远由你点。**

它不会替你发布、不会碰你的账号、不会编造你没经历过的细节。

现在处于**狗粮期**：功能已经能走通完整流程，但还没经过真实使用检验。
所以它不是"来测功能全不全"，而是——**请你像平时创作一样用它两周，看它到底帮不帮得上忙。**

## 怎么开始

1. 打开 `http://1.13.251.252:8081/`，在登录页点「**没有账号？注册**」自己开一个号。
2. 三条路，按你顺手选：
   - **想不出自己该做什么** → 「我的 → 贴参考，读出你想做成什么样」：贴 2–3 个你想做成的账号或笔记，它会读出你的选题范围、写法和读者。**贴完要等十几秒**（它在读内容）。
   - **手上有素材** → 「收件箱」丢一句话/一张图/一个链接 → 「产出架」点「拾取」→ 按提示**逐段确认** → 发布前检查 → 记录发布 → 回填数据 → 复盘。
   - **想先看看它懂不懂你** → 「机会」里点「生成内容机会」。
3. 「我的 → 创作设置」里可以打开「每晚自动整理收件箱」：晚上 03:00 它会自己把收件箱整理成初稿，你早上直接看。**私密素材永不参与。**

## 我们想知道什么（五问，随手记就行）

1. **哪一步你不知道该点什么**（不用客气，越具体越好：哪个页面、哪一句文案）
2. **哪一步你想放弃**，当时卡在哪
3. 它读出来的东西（选题/写法/读者/初稿）**像不像你**？哪一条明显不是？
4. 有没有出现"**没有这个工具，这条我就不会发**"的时刻（有几次、大概是什么内容）
5. 两周里你为它花了多少时间？（维护它 + 用它写作，大概每周多少分钟）

第 4 条最重要：它是判断"这东西值不值得做下去"的关键依据之一。

## 已经知道、不用报的

- 它需要几秒到几十秒才能出初稿（在真实调用模型，不是卡住了）；
- **发布永远是手动的**：它准备好内容，发不发由你决定，它也读不到你平台的数据，需要你回填；
- 「夜间自动整理」默认**关**，要自己在设置里开；
- 手机上能用，但界面还在打磨。

## 你的数据

- 素材默认私有；标记私密的素材不会参与任何生成；
- 你随时可以在「我的」里**导出全部数据**（JSON）或**删除账号**；
- 这个实例只给这次狗粮期用，请不要放敏感个人信息。
